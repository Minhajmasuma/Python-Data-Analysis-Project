# Python-Data-Analysis-Project

# Salary Analysis Project

# Description
This project analyzes salary data using Python, Pandas, Matplotlib, and Seaborn.

# Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

# Key Insights
- Salary distribution is right-skewed
- Outliers handled using IQR
